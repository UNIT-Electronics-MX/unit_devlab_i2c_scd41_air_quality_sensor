## **2 Ratings**

The selected UE0179 source package does not establish a complete set of electrical ratings in this reference. Do not use values from another DevLab module as substitutes.

### **2.1 Electrical Limits** {.section-page}

Supply range, I/O voltage limits, and current consumption require confirmation from the product-specific schematic and component data before integration.

### **2.2 Interface Characteristics**

Confirm the I2C address, bus speed, pull-up arrangement, and connector orientation with the released UE0179 pinout or firmware documentation. An I2C scan only identifies responding addresses; it does not verify the device protocol.
